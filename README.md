# Housing Price Analysis Using Multiple Linear Regression

## Project Overview
This project explores factors associated with median house prices using the Boston Housing Dataset.

## Dataset
- Observations: 506
- Variables: 14
- Response variable: MEDV
- Explanatory variables: 13

## Statistical Techniques
- Descriptive Statistics
- Exploratory Data Analysis (EDA)
- Pearson Correlation Analysis
- Multiple Linear Regression
- Hypothesis Testing
- Multicollinearity Analysis (VIF)
- Regression Diagnostic Tests
- Model Selection and Evaluation

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Statsmodels

## Project Files
- `Housing_Regression_Analysis.ipynb` – Analysis notebook
- `BostonHousing.csv` – Dataset
